# P13 GSS Generalized Trust — Canonical Specification v1.0
Date: 2026-09-24

## Exact construct
Canonical GSS item TRUST:
"Generally speaking, would you say that most people can be trusted or that you can't be too careful in dealing with people?"
Canonical statistic for Putnam replication: percent selecting CAN TRUST among valid substantive responses, using the appropriate GSS weight.

## Public national data
NORC/GSS publicly provides cumulative cross-sectional files. The current cumulative release spans 1972-2024.
Therefore P13 national data are publicly obtainable and should no longer be classified as unavailable.

## Geography
NORC states that geocoded variables such as states/counties require the GSS Sensitive Data Files process.
Thus:
- National P13: PUBLICLY AVAILABLE.
- State P13: RESTRICTED-GEOCODE ACCESS REQUIRED.
Do not infer state from public region variables.

## 2021+ mode discontinuity
2021 and 2022 GSS introduced web/phone mode variants TRUSTV and TRUSTNV replacing/experimenting with TRUST in portions of the cross-section.
NORC explicitly warns that the trust item is sensitive to mode of administration.
Therefore:
1. preserve classic TRUST separately;
2. preserve TRUSTV and TRUSTNV separately;
3. do not mechanically splice mode variants into a single long-run series;
4. estimate/report a mode-break sensitivity for 2021+;
5. use pre-change classic series as the strict continuity benchmark where necessary.

## Project role
P13 national generalized trust is usable immediately as:
- a national Social Capital Trust-dimension indicator;
- an external measurement anchor for state-derived social-capital aggregation;
- a national trajectory in Layer 1.

State-level P13 enters the state panel only after lawful sensitive-geocode access and sample-size/design validation.
