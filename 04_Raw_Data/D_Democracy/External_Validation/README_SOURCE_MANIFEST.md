# U.S. Democracy External Validation — Source Manifest

Status: PROVISIONAL VALIDATION SERIES; ORIGINAL PROVIDER RAW FILES NOT YET ALL ACQUIRED

## Scope
United States annual democracy measures for external validation of the Berkeley State Democracy Index (SDI2). Research window retained here: 2005–2023 where all three public comparison series can be aligned.

## Providers and acquisition status
1. V-Dem v16 (March 2026), Country-Year Core / Full+Others.
   - Official formats: CSV, STATA, R, SPSS.
   - License stated by provider: CC BY-SA 4.0.
   - Original provider download currently requires form fields including email and privacy consent.
   - Status: OFFICIAL RAW FILE NOT YET ACQUIRED.
2. Freedom House, Freedom in the World.
   - Current official download instructions request an email data request for academic/personal/nonprofit use.
   - Status: OFFICIAL RAW FILE NOT YET ACQUIRED.
3. Economist Intelligence Unit (EIU), Democracy Index.
   - Public long-run machine-readable raw series is not exposed by EIU in the same way as V-Dem.
   - Status: OFFICIAL RAW FILE NOT ACQUIRED.
4. Provisional comparison series.
   - US_DEMOCRACY_EXTERNAL_VALIDATION_2005_2023_PROVISIONAL.csv
   - Values transcribed from Pew Research Center's 2026 comparison table, which identifies V-Dem Institute, Freedom House, and EIU as underlying sources.
   - For validation/visual comparison only; MUST NOT be labeled provider raw data.

## Canonical guard
Do not overwrite SDI2. Do not merge these national measures into the 50-state panel as state-year observations. They are external-validation national series.
