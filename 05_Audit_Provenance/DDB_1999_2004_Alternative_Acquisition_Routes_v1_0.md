# DDB 1999–2004 Alternative Acquisition Routes v1.0
Date: 2026-09-24

## 1999 bridge year
Published Communication Research work pools the 1998 and 1999 DDB Life Style Studies, N=6,738 adults.
This independently confirms a 1999 survey using the same DDB Life Style architecture immediately after the historical public release period.

## 2004 educational distribution
Consumer Behavior textbook documentation states:
- the 2004 DDB Life Style Study had more than 3,300 completed questionnaires;
- hundreds of attitude/activity/interest/opinion/behavior items were collected;
- DDB allowed a portion of the 2004 data to be distributed with the textbook in spreadsheet form;
- the textbook description says those supplied data are aggregate crosstabulations with cell percentages.

Implication:
The textbook companion material is a lawful secondary acquisition lead, but it must NOT be treated as respondent microdata unless the actual companion file proves otherwise.
It may still provide exact 2004 national/subgroup tabulations or item-presence evidence.

## 2005 national civic-index evidence
America's Civic Health Index states that a valuable set of DDB Lifestyles indicators extends to 2004, with some 2005 information available.
This is additional evidence that DDB-based civic indicators continued into the mid-2000s.

## Acquisition priority
1. Obtain openICPSR Roper.sav first for P01/P02.
2. Locate the lawful 2004 textbook companion spreadsheet/disk image and inspect its variable list.
3. Search university course/textbook companion archives for the distributed DDB spreadsheet.
4. Keep searching author/institutional deposits for respondent-level 1999–2006 DDB.
5. If only aggregate textbook data are found, use them for validation/documentation only unless they contain exact state-by-item weighted tabulations.
6. Direct DDB request remains necessary for canonical state estimates if respondent/state data are unavailable publicly.

## Strict rule
Presence of an item in a textbook aggregate file does not equal canonical acquisition.
Canonical P11/P12/P14 require exact wording/statistic plus state geography and defensible weighting/sample information.
