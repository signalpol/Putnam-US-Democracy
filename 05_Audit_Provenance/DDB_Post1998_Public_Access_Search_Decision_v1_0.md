# DDB Post-1998 Public-Access Search Decision v1.0
Date: 2026-09-24

## Search conclusion
The post-1998 DDB Life Style survey continued to exist and was used by researchers, but no verified public microdata repository for the 1999-2005/06 waves has been located in the current search.

Evidence distinguishes existence from public access:
- Scholarly work reports DDB Life Style data through 2005.
- The 2004 DDB Life Style Study had >3,300 completed questionnaires.
- A consumer-behavior textbook reports that DDB allowed only a portion of the 2004 data to be distributed with the text as aggregate percentage crosstabs.
- An independent research paper states that DDB data more recent than 1999 had not been released publicly.

Therefore:
POST-1998 SURVEY EXISTENCE = VERIFIED.
PUBLIC POST-1998 MICRODATA = NOT VERIFIED / NOT ACQUIRED.

## Implication for P11/P12/P14
Do not spend project time treating ordinary web search as if a public 2000-2005 microdata download is likely to appear.
Move acquisition effort to targeted scholarly-access routes:
1. authors who received later DDB files directly;
2. author replication archives;
3. institutional data services;
4. DDB/rightsholder scholarly request;
5. exact tabulations supplied by the rightsholder if microdata cannot be shared.

Aggregate textbook crosstabs are not accepted as canonical state-year P11/P12/P14 unless they contain the exact item, state geography, weight/statistic and sample information needed for the Putnam measure.

## Historical public microdata remains high priority
The Putnam-distributed 1975-1998 DDB file remains the public historical S1 anchor and should be acquired separately. It contains YEAR, WEIGHT and STATE in the released dictionary and exact P11/P12 lineage.

## Stop rule
Do not repeatedly search generic mirrors for post-1998 DDB unless a new concrete repository/author lead appears. Preserve the access limitation and continue collecting other variables.
