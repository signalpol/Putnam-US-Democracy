# Putnam Original 14 State Table — Baseline Discovery v1.0
Date: 2026-09-24

## Discovery
Putnam's Bowling Alone research distribution explicitly provided:
- the 14 state-level measures of social capital;
- the Comprehensive Social Capital Index;
- an Excel spreadsheet version;
- a tab-delimited version.

The state table is therefore the canonical historical baseline for exact values of the original 14 indicators, not merely a reconstruction target from secondary papers.

## Implication for this project
Before recomputing historical Putnam values from Roper/DDB/GSS microdata, acquire and preserve the original 14-variable state table if the legacy file remains retrievable.
Use it to:
1. validate exact variable labels/statistics;
2. validate state coverage and missingness;
3. compare any microdata reconstruction against Putnam's published state values;
4. anchor the strict historical layer.

## Important distinction
The original state table does NOT solve the 2000-2023 extension. It is a historical baseline.
Post-2000 extension must use exact/compatible continuation data where actually observed.

## External methodological confirmation
The U.S. Congress Joint Economic Committee's 2018 Social Capital Project review notes that Putnam's original component surveys were not necessarily designed to be representative of each state and that updating the original index would require non-public/purchased data in some cases.

Therefore:
- do not fabricate annual 50-state values;
- do not interpolate strict survey variables;
- preserve irregular waves;
- report state cell sample size/reliability;
- distinguish original baseline, strict continuation, and modern extension.

## Current acquisition status
The current Putnam research page/search index confirms the historical Excel and tab-delimited state-data links existed.
The exact legacy file bytes have not yet been acquired in this environment.
