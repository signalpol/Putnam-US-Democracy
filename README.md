# Putnam-US-Democracy

Replication-extension research repository for a U.S. state-level democracy and social-capital project inspired by Robert D. Putnam.

## Storage policy
- Google Drive: full archive, including large raw source files.
- GitHub: canonical research data, variable registry, methods/audit material, and analysis code.
- Canonical panel period: 2000–2023, 50 U.S. states.
- Missing survey years are not interpolated in the canonical data.

## Current canonical data
Six variables have acquired/partial observed data: public meeting attendance, group membership, volunteering, community activity, presidential turnout, and 501(c)(3) nonprofit density.

Large raw source archives are intentionally excluded from GitHub.
